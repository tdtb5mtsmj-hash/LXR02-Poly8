# Усиление SD-загрузчика LXR-02

Этот каталог содержит overlay исходников официального загрузчика Erica Synths
для STM32F765VG. Он предназначен для сборки и проверки отдельного кандидата
загрузчика, а не для автоматической записи в устройство.

## Базовая версия

Исходный проект: https://github.com/erica-synths/lxr-desktop-bootloader

CI фиксирует исходную ревизию:
`47ed4a437a1b808581447ee01ae24b4af26c8937`

Файлы в этом каталоге накладываются поверх исходного проекта:
- `Core/Src/main.c`
- `Core/Src/flash_if.c`
- `Core/Inc/flash_if.h`

## Что изменено

1. Проверяется полное чтение заголовка и результат каждой операции FatFs.
2. Фактический размер IMG сверяется с `HEADER_SIZE + datasize`.
3. Payload должен быть ненулевым, кратным четырём и помещаться в приложение
   STM32F765VG от `0x08008000` до `0x08100000` (верхняя граница не включается).
4. Весь payload и additive checksum проверяются до стирания Flash.
5. До стирания проверяются оба первых слова vector table: начальный MSP
   (SRAM 0x20000000..0x20080000, выравнивание 8 байт) и Thumb reset vector,
   указывающий внутрь фактического payload.
6. Стираются все секторы приложения 1–7. Проверяются статус HAL и SectorError.
7. Чтение payload для записи строгое; записываются только полные 32-битные слова.
8. `FLASH_If_Write` проверяет выравнивание, диапазон, количество слов и каждое
   записанное слово; неполная запись не возвращает успех.
9. Обычный старт приложения использует ту же проверку vector table.
10. Перед передачей управления останавливается SysTick и обновляется VTOR;
    MSP приложения устанавливается перед переходом. PRIMASK намеренно не
    оставляется отключённым: приложение должно получить возможность включить
    собственные прерывания.

## Формат образа и контрольная сумма

Формат `LXRV2IMG` не меняется. Загрузчик суммирует все байты payload и байт
checksum; результат должен быть `0xFF`. Это совместимый 8-битный контроль,
а не криптографическая аутентификация: цифровая подпись образа в этой итерации
не реализована.

## CI

Workflow собирает desktop bootloader с ARM GCC и запускает статические проверки
инвариантов. Линковка должна укладываться в зарезервированный сектор 0 (32 KiB).
Также отдельно собирается Poly8 application.

## Важные ограничения перед реальным обновлением

- Успешная компиляция не доказывает работу на физическом LXR-02.
- Нет аппаратного теста SD, LCD, encoder, erase/program/readback и перезапуска.
- Загрузчик сам по себе не имеет A/B слотов или rollback. Если питание пропадёт
  после стирания приложения, потребуется восстановление приложения через ST-Link.
- Sector 0 защищён WRP, но цифровой подписи IMG нет.
- Не прошивать этот bootloader на рабочее устройство до аппаратного теста и
  проверки процедуры восстановления через ST-Link.
- Не отключать питание во время обновления.

## Сборка вручную

Из корня официального репозитория загрузчика после копирования трёх overlay-файлов:

```sh
cmake --preset release
cmake --build --preset release --parallel 2
arm-none-eabi-size build/release/LXR_V2_STM32F765_Bootloader.elf
```

Не использовать `flash_bootloader` на рабочем устройстве до завершения
аппаратной проверки.
