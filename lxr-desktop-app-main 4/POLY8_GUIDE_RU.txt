LXR-02 POLY8 — КРАТКАЯ ИНСТРУКЦИЯ

РЕЖИМ POLY8
1. Открой глобальное меню сочетанием SHIFT + LOAD/SAVE.
2. На странице глобальных настроек найди MIDI MODE и переключи OFF → ON.
   OFF = оригинальная драм-машина; ON = отдельный шестиголосный Poly8.
   При переключении Poly8 получает All Notes Off, чтобы не зависали ноты.
3. В режиме ON MIDI-ноты поступают в шестиголосный Poly8; оригинальные ударные
не рендерятся. В режиме OFF восстанавливается исходный звуковой тракт драм-машины.

ГРОМКОСТЬ
- Фейдеры 1–6 управляют громкостью голосов Poly8 1–6 независимо.
- MASTER находится в глобальном меню: вторая страница глобальных настроек,
  второй экран (после MIDI MODE).
- В аппаратной раскладке LXR-02 шесть физических фейдеров; отдельного
  седьмого фейдера Master нет.

НАСТРОЙКИ ОСЦИЛЛЯТОРНЫХ СЛОЁВ
- В Poly8 есть шесть независимых осцилляторных слоёв; фейдеры 1–6 регулируют их громкость.
- MIDI-полифония отделена от слоёв: каждый слой воспроизводит все одновременно удерживаемые ноты.
  Поэтому даже при поднятом только одном фейдере можно играть аккорды.
- Выбери секцию голоса 1–6 обычными кнопками/страницами LXR и переключай её страницы
  сочетанием SHIFT + LOAD/SAVE. Для каждого слоя доступны шесть страниц:

1. OSC — Waveform (Saw, Square, Triangle, Sine).
2. ENV — Attack, Decay, Sustain, Release.
3. FILTER — Cutoff, Resonance.
4. FM — FM Amount, FM Ratio (0.125x–16x), FM Waveform.
5. PITCH — Coarse Pitch (±24 полутона), Fine Pitch (±100 центов).
6. LFO/MOD — LFO Rate (0,05–20 Гц), Mod Amount, LFO Wave, Target.

LFO/MOD Target:
- Pit (0) = Pitch (до ±12 полутонов);
- Cut (1) = Filter Cutoff (до ±3 октав);
- FM (2) = FM Amount.

Повторное переключение циклически проходит OSC → ENV → FILTER → FM → PITCH → LFO/MOD.
СОХРАНЕНИЕ
Poly8-параметры являются глобальными. Для сохранения используй SAVE GLO или SAVE ALL.
Обычный KIT/SOUND-файл не является местом хранения этих глобальных параметров.

ВАЖНО
Исходный ZIP содержит код, а готовый IMG публикуется отдельно как артефакт
GitHub Actions с именем LXR_V2_V1.7-Poly8. В артефакте находятся:
- LXR_V2_V1.7.img — файл обновления для SD;
- LXR_V2_V1.7.img.sha256 — контрольная сумма для проверки после скачивания.

На macOS помести оба файла в одну папку и выполни:
shasum -a 256 -c LXR_V2_V1.7.img.sha256

Команда должна вывести OK. Копируй на SD только сам .img-файл, в корень карты.
Не переименовывай его и не извлекай IMG из ZIP исходников.

CI проверяет сборку STM32F765, host DSP-тесты, структуру LXRV2IMG, точную длину
payload, выравнивание по 4 байта, размер области приложения, адрес reset vector
и контрольную сумму. Это подтверждает корректность собранного файла, но не
заменяет испытание на физическом LXR-02.

ВАЖНО ДЛЯ БЕЗОПАСНОСТИ
Официальный SD-загрузчик Erica Synths в этом проекте не изменён. Его отдельный
аудит выявил недостаточную проверку ошибок/короткого чтения, статуса стирания
Flash и записи последнего неполного слова. До установки через SD необходимо
отдельно исправить и проверить загрузчик и иметь план восстановления через
ST-Link. Не отключай питание во время обновления.
