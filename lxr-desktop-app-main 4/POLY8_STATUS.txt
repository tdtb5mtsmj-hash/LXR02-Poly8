LXR-02 Poly8 — final hardening candidate (2026-10-31)

РЕАЛИЗОВАНО
- Шесть MIDI note slots управляют шестью независимыми oscillator layers: до 36
  путей note/layer. Один включённый слой может играть аккорд до шести нот.
- MIDI Note On/Off маршрутизируются в Poly8 при PAR_MIDI_MODE=ON; OFF сохраняет
  исходный тракт драм-машины.
- Фейдеры 1–6 управляют уровнями шести слоёв независимо. Каждый gain применяется
  к своему слою до суммирования; PAR_POLY8_VOL — отдельная общая громкость после
  суммирования.
- Нормализация больше не делится на сумму значений фейдеров: снижение уровня
  одного слоя не компенсируется автоматическим подъёмом остальных.
- При изменении параметров слоя сохраняется текущее положение аппаратного фейдера.
- Каждый слой имеет собственные Waveform, ADSR, Filter, FM, Pitch и LFO/MOD.
  LFO destinations в меню подписаны Pit, Cut и FM.
- Poly8 встроен в существующий mixer output path; при выключенном Poly8
  сохраняется исходная драм-машина.
- Параметры сохраняются в глобальном блоке. Совместимость ALL:
  v1/v2 — 38 параметров в блоке 64 байта;
  v3 — 110 параметров в блоке 128 байт;
  v4 — 134 параметра в блоке 160 байт.
- При загрузке старых файлов отсутствующие Poly8/LFO параметры получают
  defaults; глобальные параметры копируются в activeParameters только после
  успешного полного чтения.

ПРОВЕРКИ CI
- Host DSP smoke test: шестинотный аккорд, линейность каждого фейдера,
  отдельная линейность Master, сохранение уровня при редактировании параметров,
  тишина при всех опущенных фейдерах, LFO и stress test всех 36 путей.
- Проверка preset layout: 38/64, 110/128, 134/160 и наличие безопасных defaults.
- Полная сборка STM32F765 release.
- Проверка IMG: LXRV2IMG magic, точная длина payload, выравнивание 4 байта,
  предел 992 KiB, диапазон reset vector и additive checksum.
- Артефакт CI содержит IMG и SHA-256 sidecar; SHA-256 sidecar создаётся с
  относительным именем файла, чтобы команда macOS shasum -a 256 -c работала
  после распаковки артефакта.

ОГРАНИЧЕНИЯ
- Физический LXR-02 не подключён: звук, MIDI, фейдеры, дисплей, сохранение на SD
  и обновление через SD на устройстве не тестировались.
- Официальный SD-загрузчик Erica Synths не изменён. Его проблемы описаны
  в BOOTLOADER_AUDIT_RU.txt. Перед SD-установкой нужна отдельная проверенная
  версия загрузчика и план восстановления через ST-Link.
- CI-проверка IMG не является криптографической подписью и не устраняет
  ошибки загрузчика. Не отключать питание во время обновления.

Исходный код и инструкция находятся в этом каталоге. Готовый IMG публикуется
отдельным артефактом GitHub Actions: LXR_V2_V1.7-Poly8.
